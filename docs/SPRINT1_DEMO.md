# Sprint 1 Demo Guide

## Target runtime

Start the application with:

```bash
npm install
npm start
```

Open `http://localhost:3000`.

## Demo account

## Suggested 1-minute flow

1. Show the GitHub Project with Sprint 1 items.
2. Open the BMS login screen.
3. Enter the demo credentials.
4. Enter the OTP.
5. Show the dashboard and current account balance.
6. Perform a small deposit.
7. Perform a withdrawal.
8. Add the second demo account as a beneficiary if needed.
9. Transfer a small amount to `1000002001`.
10. Refresh and show transaction history.
11. Briefly show the passing GitHub Actions check on PR #50.

## Evidence checklist

- Login and OTP
- Dashboard/balance
- Deposit
- Withdrawal
- Fund transfer
- Transaction history
- Passing GitHub Actions
- PR and review request
- Project board
